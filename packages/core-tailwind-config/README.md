# @zyplot/core-tailwind-config

Zyplot's Tailwind CSS v4 setup and design-token source of truth.

- `@zyplot/core-tailwind-config` exports the shared primitives, semantic tokens, chart palette, typography and light/dark values.
- `@zyplot/core-tailwind-config/postcss` exports the PostCSS configuration.

Applications opt into dark mode by placing the `dark` class on an ancestor, normally `<html>`.
